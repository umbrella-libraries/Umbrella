# Claude Code instructions

For this repository, Claude should use:

- `CLAUDE.md` for repo-level guidance
- `.claude\agents\` for Claude agent entrypoints (generated — do not edit directly)
- `.claude\skills\` for Claude skill documentation and wrappers (generated — do not edit directly)
- `nuget-upgrade-exclusions.json` for repository-specific package policy

## NuGet safe upgrade agent

Use the `nuget-safe-upgrade` Claude agent for package-management work that must stay compatible across multiple target frameworks.

### Required behavior

1. Read `nuget-upgrade-exclusions.json`.
2. Use the generated `.claude\skills\nuget-safe-upgrade\scripts\Invoke-NuGetSafeUpgrade.ps1` (source: `.ai-shared\skills\nuget-safe-upgrade\scripts\`) instead of manually editing package versions.
3. Preserve target-framework-specific version lines.
4. Validate accepted candidates with restore and resolved-package inspection.
5. Return successful, skipped, and blocked packages with clear next-step options.

## Skill authoring conventions

All canonical skill files live under `.ai-shared\skills\<name>\`. The `.claude\skills\` and `.github\skills\` directories are **generated outputs** — do not edit them directly.

When writing or updating any skill:

- Edit `.ai-shared\skills\<name>\SKILL.md` (the single source of truth).
- Run `umbrella-ai sync` (or `dotnet run --project Tools\src\Umbrella.AI.Tools -- sync`) to regenerate `.claude\skills\` and `.github\skills\`.
- Commit both the canonical source and the regenerated files.
- Use `IndyRecords` as the fictional placeholder for the client project name in all examples, descriptions, and code templates (e.g. `IndyRecordsGenericRepositoryApiController`, `IndyRecordsPageTitle`).
- Never embed real client names — ThriveForSend, WarwickUniversity, JustCalculators, CRUGroup, Just.DestinationRetirement, ProjectBole, or any other — anywhere in skill files.
- For multi-segment namespace examples, use `IndyRecords`, `VinylVault`, and `SpinCity.Marketing` as the fictional stand-ins.
- In code examples that reference the script path, use `{{skill_dir}}` as the placeholder — the sync tool resolves it to the correct adapter path (`.claude\skills` or `.github\skills`) in each generated copy.

Agent files follow the same pattern: edit `.ai-shared\agents\claude\` or `.ai-shared\agents\github\`, then run `umbrella-ai sync`.

## Shared implementation

All shared scripts and schemas live in `.ai-shared\`. The `.claude\` and `.github\` adapter directories are generated by `umbrella-ai sync` / `umbrella-ai install`.

- `.ai-shared\skills\` — canonical skill SKILL.md files and scripts
- `.ai-shared\agents\claude\` — Claude Code agent manifests
- `.ai-shared\agents\github\` — GitHub Copilot agent manifests
